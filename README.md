# -MAD-Project-MacroPlate
A Capstone project for a fitness, nutrition, and meal prep app

Project Description

MacroPlate helps Ethiopian fitness enthusiasts and bodybuilders achieve their cutting, maintaining, or bulking goals by providing personalized meal plans based on individual body metrics and fitness objectives. Users can customize their daily protein sources and schedule delivery of fresh meal kits directly through the app, removing the guesswork and time commitment from fitness nutrition.
